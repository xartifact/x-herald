# Git 提交规范

## 提交信息格式

```
<type>: <description>
```

## Type 类型

- `feat`: 新功能
- `fix`: Bug 修复
- `refactor`: 代码重构
- `docs`: 文档更新
- `chore`: 构建/工具/其他

## 示例

```
feat: 添加供应商管理页面
fix: 修复 API 路由 404 错误
refactor: 优化数据库查询性能
docs: 更新开发文档
chore: 更新依赖版本
```

## 注意事项

- 提交信息使用中文
- 描述简洁明了，说明"做了什么"而非"怎么做"
- 单次提交保持单一职责
