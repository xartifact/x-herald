## 概述

意图路由（Intent Routing）使用小型 LLM 模型分析用户请求的语义，根据意图将请求转发到适合的模型组。

## 流程

```
请求到达 → 小模型意图分析
         ↓
     [分类结果]
    ┌────┴────┐
  复杂查询    简单查询
    │          │
    ↓          ↓
强力模型   轻量模型
(GPT-4o)  (GPT-4o-mini)
```

## 配置项

| 字段              | 类型                   | 说明                 |
| ----------------- | ---------------------- | -------------------- |
| `classifierModel` | string                 | 用于意图分类的小模型 |
| `categories`      | string[]               | 预定义意图分类列表   |
| `routingTable`    | Record<string, string> | 意图 → 模型组映射    |
| `defaultGroup`    | string                 | 未匹配时的兜底模型组 |

## 实现要点

1. 意图分析在请求转换后、发送到目标模型前执行
2. 分类模型使用低成本、低延迟模型（如 gpt-4o-mini）
3. 分类结果缓存在请求上下文中，避免重复分析
4. 分类 prompt 包含预定义分类和示例

## 测试用例

| 场景       | 输入                  | 预期路由                                          |
| ---------- | --------------------- | ------------------------------------------------- |
| 模型名匹配 | `model: gpt-4-coding` | coding 组                                         |
| 默认路由   | `model: gpt-4o`       | general 组                                        |
| 视觉内容   | image_url present     | 由 capability 节点处理（stateless，只发当前回合） |
| 工具调用   | tools: [...]          | 由 capability 节点处理                            |
