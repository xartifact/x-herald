## 📅 开发阶段

### Phase 2.1: 管理员认证 (优先级最高) ⭐⭐⭐

**用户故事**: 作为管理员，我需要登录系统才能进行配置

- [ ] **任务 2.1.1**: 实现管理员认证 API
  - `POST /api/auth/login` - 登录（简单密码验证）
  - `POST /api/auth/logout` - 登出
  - `GET /api/auth/me` - 获取当前用户信息

- [ ] **任务 2.1.2**: JWT 认证中间件
  - 生成 JWT token
  - 验证 JWT token
  - 保护管理 API 路由

**交付**: 管理员可以登录系统

---

### Phase 2.2: 供应商管理 (核心配置) ⭐⭐⭐

**用户故事**: 作为管理员，我需要添加 LLM 供应商（如 OpenAI、Anthropic）

- [ ] **任务 2.2.1**: 供应商 CRUD API
  - `POST /api/providers` - 创建供应商
  - `GET /api/providers` - 列出供应商
  - `GET /api/providers/:id` - 获取供应商详情
  - `PUT /api/providers/:id` - 更新供应商
  - `DELETE /api/providers/:id` - 删除供应商

- [ ] **任务 2.2.2**: 供应商验证
  - 验证 API Key 有效性
  - 测试连接功能

- [ ] **任务 2.2.3**: 前端管理界面
  - 供应商列表页面
  - 添加供应商表单
  - 编辑供应商表单

**交付**: 管理员可以管理供应商

---

### Phase 2.3: 模型管理 (核心配置) ⭐⭐⭐

**用户故事**: 作为管理员，我需要配置可用的模型

- [ ] **任务 2.3.1**: 模型 CRUD API
  - `POST /api/models` - 创建模型
  - `GET /api/models` - 列出模型
  - `GET /api/models/:id` - 获取模型详情
  - `PUT /api/models/:id` - 更新模型
  - `DELETE /api/models/:id` - 删除模型

- [ ] **任务 2.3.2**: LiteLLM 预设集成（可选）
  - 导入 LiteLLM 模型定义
  - 自动填充模型信息

- [ ] **任务 2.3.3**: 前端管理界面
  - 模型列表页面
  - 添加模型表单
  - 模型与供应商关联

**交付**: 管理员可以管理模型

---

### Phase 2.4: 虚拟密钥生成 (用户访问) ⭐⭐

**用户故事**: 作为管理员，我需要生成密钥给终端用户

- [ ] **任务 2.4.1**: 虚拟密钥 CRUD API
  - `POST /api/keys` - 创建密钥
  - `GET /api/keys` - 列出密钥
  - `GET /api/keys/:id` - 获取密钥详情
  - `DELETE /api/keys/:id` - 删除密钥

- [ ] **任务 2.4.2**: 密钥生成逻辑
  - 生成安全的密钥字符串
  - 配置模型访问权限
  - 配置速率限制

- [ ] **任务 2.4.3**: 前端管理界面
  - 密钥列表页面
  - 生成密钥表单
  - 查看密钥详情（含密钥字符串）

**交付**: 管理员可以生成虚拟密钥

---

### Phase 2.5: 基础代理功能 (终端用户调用) ⭐⭐⭐

**用户故事**: 作为终端用户，我使用虚拟密钥调用 API

- [ ] **任务 2.5.1**: 密钥认证中间件
  - 验证 Bearer Token (虚拟密钥)
  - 检查密钥是否有效、未过期
  - 检查模型访问权限

- [ ] **任务 2.5.2**: 基础代理逻辑
  - `POST /v1/chat/completions` - OpenAI 兼容接口
  - 解析目标模型
  - 转发到对应供应商
  - 返回响应

- [ ] **任务 2.5.3**: 请求日志记录
  - 记录请求信息
  - 统计 token 使用
  - 记录响应状态

**交付**: 终端用户可以使用虚拟密钥调用 API

---

### Phase 2.6: 测试与文档 (质量保证) ⭐
